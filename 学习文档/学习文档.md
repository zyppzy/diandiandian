## mlp训练
前向传播：从输入层到输出层，最终得到一个预测值
计算损失：比较输出值和真实值，使用损失函数量化误差--**交叉熵/均方误差**.etc
反向传播：从输出层开始，利用**链式法则**逐层向后计算每个**权重和偏置的梯度**
参数更新：使用梯度下降法，按照学习率调整所有权重和偏置，使损失函数值减小
重复迭代：……
## mlp
逆向映射：并非反推输入——基于误差，计算如何调整参数使误差减小
**逆向映射的本质是梯度传播**：它利用损失函数对输出的导数，逐层回传，计算每个参数的梯度，从而指导参数更新

# level2
## cnn
通过卷积核在像素上滑动完成信息识别
从**输入层->隐藏层->隐藏层->输出层**
区别是在于每层的计算方式不同
mlp是一维张量，做矩阵乘法，丢失了空间的结构
cnn是二维张量，cnn通过卷积提取信息，池化降采样进入下一层->减小特征图尺寸，减小计算量
展平后接全所有连接层，输出类别
cnn的参数量为421642，mlp参数量为235146，cnn将近是mlp的两倍，CNN 的卷积层参数很少，但 64 个通道让展平后的特征向量（3136）比原始像素（784）大 4 倍，导致全连接层参数暴增
cnn的收敛速度明显高于mlp，原因在于cnn3\*3的卷积核，利用了相邻像素之间临近的关系，层与层之间通过池化保留特征分层抽象，简化了学习目标，而mlp中784个输入维度，每个神经元连接了所有像素，减慢了学习速度

# level3
## 残差与resnet
残差：解决epoch到达一定数量后模型”优化不动“的问题输入
  x
  ├──> [卷积 → BN → ReLU → 卷积 → BN]  →  F(x)
  └──> (恒等映射，什么都不做)          →  x
                 ↓ 相加
             F(x) + x
                 ↓ ReLU
               输出
e.g. 如果网络觉得在某一层什么都不需要做，直接令F(x)=0  恒等映射，至少不会让网络参数退化
作用：梯度可以直接传回上一层，不会经过矩阵的逆运算，保证了一部分梯度可以”无损”传到输入层，避免了梯度的衰减

## BatchNorm2d
**批归一化（Batch Normalization）**：对每一层卷积输出的特征图，按通道做标准化，把数值拉回到一个稳定的范围，再让它自己学一个合适的缩放和平移
这样就允许了更大的学习率，不用太担心某层输出数值爆炸/消失，可以调大 lr 加快收敛

网络越浅与不需要bn，网络层数加大时每一层的误差层层积累，bn把数值拉回稳定范围

## alexnet和resnet的对比
可以发现resnet网络的模型大小更小
alexnet的数据量主要集中在全连接层，reesnet通过平均池化，把每个通道压缩为一个数，代替链接层，最后只需要一个很小的连接层

## 再复习一下resnet的结构
每一层里面放多个block块->第一个负责降采样，提升通道数，压缩图片尺寸//后面的block负责“充分提取特征”，最后压缩到一个像素块，再通过linear连接到十个类别的输出

# level4
## 有点复杂 先梳理一下思路
需要分辨：1.手写部分  2.空白部分  3.印刷部分  4.手写与印刷重合部分

### 网络结构
输入：单通道灰度图片 in_channals=1 像素经过处理得到256\*256或者512\*512
	4~5层的下采样，通道数目增加，64 → 128 → 256 → 512 → 1024
	解码器对称上采样，跳跃连接拼接编码器特征
		图片最终的输出还是原尺寸的图片，所以需要按照编码的过程对称还原图片，从高级的“特征图”还原到低级的“细节图”，只靠解码器自己上采样是不够的，因为下采样丢掉的空间细节回不来了，解决办法就是把编码器同一层级的特征图，通过跳跃连接直接"拼接"给解码器对应的那一层
	瓶颈（特征图最小 通道最多的地方，像沙漏中间）可用`CBAM`/ 通道注意力增强，对“区分手写与印刷”有帮助
		给每一个通道增加权重，再按照权重缩放各个通道，权重高的被增强，权重低的被抑制，提高对于手写部分识别的注意力
	可加残差连接：输出=输入+网络预测的残差墨迹、有点类似于resnet

### 损失函数  我们来逐个解释
#### L1/CharBonnier
`L = sqrt((pred - target)^2 + eps^2)`最终是取绝对值，墨迹边缘是梯度大误差大的地方。若误差被平方后惩罚也大，使得锐利的文字边缘被模糊，图像失去了细节--灰蒙蒙的
#### SSIM
结构项，把注意力集中到有问题的结构区域，对于文档本身的大部分空白可以减少权重，防止文字被稀释掉
#### 感知损失
人如其名，通过预训练好的网络，比较两张图片的特征图的差别，通过神经网络后比较两张图“感觉起来哪里不一样”
#### 掩码监督
网络额外输出一张含有手写标注的图片，将手写像素标注为1，其余标注为0，将手写消除（消除-复原被手写掩盖的印刷部分），拆分为两步，指示网络先标注出手写像素
Focal loss给容易分辨的像素降低权重
Dice loss 比值，惩罚全0预测，判断预测数量和实际数量是否相同
#### 对抗损失
附加的损失函数，鼓励网络大胆输出锐利的细节，消除模糊感-> 具有不稳定性，可能会编造，所以权重非常低
